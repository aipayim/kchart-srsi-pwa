## 一、手机/PAD 盯盘体验（PWA 资深产品视角）
现状痛点：K线读数/信号详情依赖鼠标 hover；交易按钮小；页面为桌面布局。
1. **点按取值替代悬停**：K线点按=显示该根 OHLC/SRSI 读数（复用 mainHoverAt/subHoverAt 纯函数，touchstart 映射 idxFromFrac）；长按=锁定十字线（第二根点按解锁）
2. **信号常显**：盯盘信号卡（左居中）本就常显——手机上保持，缩放至 `zoom` 适配（已有 pwa_zoom）
3. **底部 Tab 导航**（拇指区）：K线 / 回测 / 实盘 / 设置——kchart.html 单页内切 panel 显隐（无路由改动）
4. **开平仓固定拇指区**：主图底部固定「▲开多 / ▼开空 / 平仓」条（≥44px 高），复用现有防误触（arm+3s 确认）
5. **横屏 PAD**：`@media (orientation:landscape)` 交易面板自动展开双栏
6. 优先级：②④ 一批（改动最小收益最大）→ ①③ 一批 → ⑤ 收尾

## 二、交易信号准确率提升路线（数学边界内，按 GOAL16 框架）
前提：准确率提升只能来自三层——更好的方向源/更好的时机过滤/更好的风控，**不是调 SRSI 参数**（GOAL10 证平台、GOAL11 证长窗失效）。
1. **方向层增强（最大杠杆）**：Alpha 现为日频调仓（carry+momo+brk）。候选增量因子（每个都走 GOAL16-B 式长窗验证）：
   - 资金费率动量（FR 变化率——拥挤度拐点早于绝对水平）
   - OI 变化 × 价格方向（新多/新空/多头平仓/空头回补四象限）
   - BTC 主导率（alt 跟随 Beta 调整仓位）
2. **时机层降频确认**（直接回应 GOAL16-B 成本问题）：SRSI 时机信号加「确认 bar」（信号出现后收盘确认才有效）或升级到 1h 带——预期笔数 ÷3~5、免成本边缘保留、成本占比降一个量级
3. **风控层**：regime 闸门三态（高波启用卫星/低波降杠杆/阴跌观望）——GOAL15 候选，数学框架 §三 的离散自适应层
4. **数据质量**：funding 已修（GOAL14）；tick 级实时性受 15m 粒度限制（可接受——人工盯盘场景）

## 三、验证标准（每个增量都过）

- 样本外（后 1/3 窗口）方向一致
- 成本后口径（0.13%/往返）
